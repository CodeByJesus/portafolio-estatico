Sobre Mí

De construir aplicaciones a garantizar que funcionen perfectamente.

Comencé como desarrollador backend con Django, pero descubrí mi verdadera pasión: asegurar que el software no solo funcione, sino que funcione perfectamente en todo momento. Hoy me especializo en automatización de testing y análisis de calidad con Python.

¿Qué hago?

Creo frameworks de testing automatizado que detectan bugs antes que los usuarios. Diseño herramientas que validan APIs 24/7. Construyo sistemas que analizan datos y generan reportes sin intervención humana. Y exploro cómo la automatización puede fortalecer la seguridad de aplicaciones.

Mi stack de automatización:
  • Testing: Selenium WebDriver, PyTest, Page Object Model
  • APIs: Requests, schema validation, performance testing
  • Data: Pandas, automatización de reportes, data quality
  • Security: análisis de vulnerabilidades, pentesting automation

Mi objetivo es integrar equipos de desarrollo como QA Automation Engineer, donde pueda aportar calidad mediante código, no solo documentos.
