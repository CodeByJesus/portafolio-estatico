Synapse - Asistente de Datos

Proyecto educativo completo de análisis de datos con Django. Incluye análisis automático de datasets, detección de valores faltantes, limpieza de datos con múltiples estrategias, visualizaciones interactivas (barras, líneas, dispersión), generación de reportes PDF profesionales y soporte multilingüe. Demuestra habilidades avanzadas en análisis de datos y desarrollo web full-stack.

Tecnologías: Python, Django, Pandas, NumPy, Matplotlib, Chart.js, ReportLab, Bootstrap, HTML, CSS, JavaScript, SQLite, Font Awesome.
